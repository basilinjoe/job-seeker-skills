# References

Loaded on demand by the skill; `SKILL.md` says which file each mode and task reads.

- `mode-*.md` — one procedure per mode (setup, braindump, resume, tailor, ship, refresh, gaps,
  pipeline).
- `kb-format.md` — the career's format as `jsk kb show` prints it, and changesets. `resume-format.md` — a
  selection (resume.json's keys, in the store): the bullets chosen for one resume, by id, and its
  settings.
- `writing-rules.md`, `ats-rules.md`, `templates.md` — what good looks like.
- `rationale.md` — why each rule exists, for when someone asks.

A `rules/` directory beside `career/` can override three of them: `writing-rules.md`, `ats-rules.md`,
and `structure-rules.md` for the structure rules at the foot of `mode-resume.md`.
